# work design

**Not sure which skill? Say "work-design".**

The set has a skill for every moment a piece of work goes right or wrong, from the first plan to the lessons at the end. The names are phrases you would say anyway: `get-unstuck`, `review-my-work`, `how-long-will-it-take`. This skill is the fallback for the days you cannot remember any of them.

The failure this exists to prevent: **never starting, or never finishing, because nobody remembers which skill fits the moment they are in.**

**Reach for it:** whenever you have work and no idea which skill to use. Part of [work-design](https://github.com/theAnirudhKumar/work-design).

---

## Example

*Illustrative. The exact output varies with what you give it.*

You type: `work-design. I've got a grant application due in three weeks and I haven't started.`

You get (shortened):

```
Stage: not started, with a fixed deadline.

1. plan-the-work: turns this into a one-page card (outcome, what done
   looks like, biggest risk, first move). Say: "Where do I start on this
   grant application?"
2. fit-to-deadline: if the plan comes out bigger than three weeks, it
   cuts the work to a version that fits. Say: "I only have three weeks."

(Assumed you are writing it yourself. If part of it goes to a colleague
or an AI, add: "What should I hand off?" for delegate.)
```

---

## What it does not do

It does not plan, estimate, review or get you unstuck on anything. It names the skill that does. If your message already says "I'm stuck" or "is this good enough to send", the matching skill answers directly and this one stays out of the way.

---

## What this needs

Nothing. No files, tools or connectors.
