# Context checklist

What this skill may look at to make a suggestion specific, in order, and what it may and may not do with it. The aim is a better suggestion, never surveillance.

## 1. What is already in front of you (no permission needed)

- The user's words in this conversation.
- Earlier turns of the conversation.
- Notes or memory the AI tool has already loaded into this session (for example a project instructions file, a memory file, a saved preference).
- A `my-system.md` the user pasted.

Use these freely. Do not go searching for more.

## 2. Things to ask before reading

Ask once, in one sentence, and wait for a yes:

- **A connected calendar.** Read this week only. Look at: how many hours are meetings, the longest unbroken free block, how many meetings are back to back, whether any evening or weekend time is booked.
- **A connected task list.** Look at: how many items are overdue, how many have no date, how many have been moved more than twice, how old the oldest open item is.
- **Files or folders the user names.** Read only what they name.

Do not ask for email or chat history. If the user offers it, take only what they point to.

## 3. How to use what you read

- Turn it into counts and patterns, not quotes: "11 of your 16 working hours today are meetings".
- State what you looked at in the "What I looked at" line of the Read.
- Use it for this suggestion only.

## 4. What never to do

- Never write, send, schedule, move or delete anything while looking.
- Never save what you learned to memory or a file without asking. If the AI tool has a memory-write approval step, propose the entry and wait.
- Never repeat sensitive content back (health, money, other people's names or messages) beyond what the suggestion needs.
- Never read more than the user agreed to, and never read a calendar or task list that was not offered by the user or the tool for this purpose.
- Never infer a diagnosis, a personality or a motive.

## 5. If nothing is available

Ask the one question in the skill, or say plainly that the suggestion rests on assumptions and list them.
