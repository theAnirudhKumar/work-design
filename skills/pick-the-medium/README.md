# pick the medium

**Part of [work-design](../../#readme): a set of skills, in three categories, for deciding how a piece of work will run before it starts.**

Most communication overhead isn't a bad meeting or a bad message, it's the wrong one - a decision needing five minutes of back-and-forth gets a thirty-minute meeting because someone said "let's hop on a call" out of habit before asking what the decision actually needed. This skill names what actually has to happen (a decision made, information moved one direction, live reactions gathered from several people, or a durable record created), then runs it through reversibility - the biggest lever, since most mismatches are a reversible call routed through a slow synchronous channel out of unnecessary caution - how many people genuinely need to be live at once (an audience is not attendance), and what waiting for a reply actually costs here. It lands on one medium from a fixed table, names the runner-up, and states in one sentence what the runner-up would have cost. The instant the answer is a meeting, it hands off to a meeting-design skill for the agenda and attendee list rather than building either itself.

The failure this exists to prevent: **choosing the medium out of habit before asking what the decision needs.**

Part of the **Deciding how work runs** group in this repository.

## Who this is for

For anyone shaping a piece of work before committing time to it: an estimate, a channel choice, or a scope line.

## What this needs

Works with nothing but what needs to get decided or conveyed. Gets better with how reversible the decision is and whether this will come up again in this shape, which is what tells a one-off from a pattern worth fixing.

Missing context never blocks this skill. It changes what the skill can honestly claim, and it says which checks it could not run rather than guessing around the gap.

## Install just this skill

**In the Claude app, no terminal needed.** Paste this into Claude:

```
Download the pick-the-medium skill from
https://github.com/theAnirudhKumar/work-design/tree/main/skills/pick-the-medium,
zip the pick-the-medium folder on its own, then upload it as a skill in Claude.
```

Or do it by hand: download this repository as a ZIP (or clone it), zip this folder (`skills/pick-the-medium`) on its own, then in Claude go to **Customize > Skills > Create skill > Upload a skill**. The folder name inside the ZIP has to match the `name` in `SKILL.md`.

## Want the whole set?

The [main README's Install section](../../#install) has the one-line plugin command that installs the whole set at once, plus the API and by-hand routes.
