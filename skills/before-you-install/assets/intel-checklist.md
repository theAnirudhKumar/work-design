# The intel checklist

Run this yourself, or hand it to an agent that has web access. Each line is a thing to find, and a place to find it. Mark anything you could not confirm rather than leaving it blank.

Tool: ______________________  Date checked: __________

## 1. Privacy and data

- [ ] Read the privacy policy end to end. Note anything that surprised you
- [ ] Terms: is there a licence to use, reproduce or train on content you upload? Quote the clause
- [ ] What happens to your data when you delete your account, and how long is it retained
- [ ] Which third parties or sub-processors receive your content
- [ ] If there is a "privacy mode" or "local mode": what does it actually cover, and what still leaves the machine
- [ ] Where is data stored, and under which country's law

## 2. Business model

- [ ] If it is free, how does it make money
- [ ] Has the company been acquired. By whom, and when
- [ ] Did the terms or pricing change after that
- [ ] Is the current price confirmed on the vendor's own pricing page, or only in third-party reviews
- [ ] Is there a usage cap on the free tier, and what is it

## 3. Permissions and footprint

- [ ] What permissions does the installer request: screen recording, accessibility, microphone, camera, clipboard, files, contacts
- [ ] For each one, which visible feature needs it
- [ ] Does it run in the background or add itself to startup
- [ ] Does it install a browser extension, and what does that extension request
- [ ] Which platforms are actually supported today, checked on the vendor's site

## 4. The public record

- [ ] Search: `<tool> reddit`
- [ ] Search: `<tool> controversy` and `<tool> complaints`
- [ ] Search: `<tool> privacy concern` and `<tool> data collection`
- [ ] Search: `<tool> cancel subscription` and `<tool> refund`
- [ ] Search: `<tool> alternative` to find who the unhappy users left for
- [ ] Note whether a complaint is one person or a repeated pattern, and how old it is
- [ ] Note how the company responded when criticised publicly

## 5. Scale and staying power

- [ ] Roughly how many users. Extension store install counts, app store review counts, public launch numbers
- [ ] How long has it existed, and who is behind it
- [ ] Are safety or security claims independently audited, or maker-stated only
- [ ] Can you export your data, in what format, and did you check that the export works

## 6. Buried value

- [ ] Features that are real and useful but not on the landing page
- [ ] Integrations or use cases the marketing does not lead with
- [ ] Anything in the docs or settings that changes how good the tool is

## Before you decide

- [ ] Which findings actually matter for what you will put into it
- [ ] Which are conditions you can set rather than reasons to stop
- [ ] What you could not confirm, written down as such
